# The GIFASH Levels LIST

The GIFASH Levels LIST is a Geometry Dash community list ranking hard levels, featuring level information, videos, records, a leaderboard, and roulette.

## Run it locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Publish it with GitHub Pages
1. Create a new public repository on GitHub (for example, `the-gifash-levels-list`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show your website URL in the Pages section.

## Customize
Edit the `levels` array near the top of `script.js` to add your levels and information.
Replace the demo level video area with YouTube embed URLs when you're ready.

Note: the submit form is currently a front-end demo. It does not store submissions. A database or form service is needed for real submissions.
